# Liquid d1-3B WS1 profile

The selected checkpoint and its Python source are `LiquidAI/d1-3B` at revision
`051bcc464b01b9f92942b364d9586b0ef5912432`. The LFM2.5-VL-3B-based model
accepts text and images. The user verified Noul, Choice and Score for text on
an NVIDIA H200 using BF16 and the official in-process `D1Model` Python API.
No quantization or HTTP server was used. Vision remains unvalidated.

The smoke adapter handles one text question per request. It preserves the
official option-token groups and per-token logits. The official readout takes
the maximum logit in each group and softmaxes the resulting option scores.
The user-verified outputs also preserve the native response and option-ID
probability mapping. The official default runtime passes no separate post-hoc
calibration object: the calibrated probability field is null, and native
probabilities are the default pending separate calibration evaluation.

The official release is described in the Liquid AI article; the LFM2 technical
report describes the backbone rather than being a d1-specific methods paper.
The checkpoint uses LFM Open License v1.0, which has commercial-use conditions.
An official d1 training script and LoRA compatibility remain unverified; WS1
has not run or implemented fine-tuning.

Sources: <https://huggingface.co/LiquidAI/d1-3B>,
<https://www.liquid.ai/blog/d1-open>, and <https://arxiv.org/abs/2511.23404>.
